# Belajar Kotlin Android

Kumpulan project latihan belajar Kotlin untuk Android, dibuat dengan Android Studio.

## Daftar Project

| Project | Deskripsi |
|---|---|
| `ProfilePage` | Latihan menampilkan halaman profil dengan Jetpack Compose |
| `ToDo` | Aplikasi To-Do list (ViewModel + Repository) |
| `kalkulatorTip` | Kalkulator tip sederhana |

## Cara Menjalankan

1. Buka folder project (`ToDo/`, `ProfilePage/`, atau `kalkulatorTip/`) di Android Studio.
2. Tunggu Gradle sync selesai.
3. Jalankan pada emulator atau perangkat Android.

## Catatan

- Setiap project memiliki `gradle wrapper` sendiri — tidak perlu install Gradle manual.
- File `local.properties` (path SDK) tidak ikut di-commit karena spesifik per mesin.
